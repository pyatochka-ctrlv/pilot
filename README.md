# Зона турбулентності

Інтерактивна гра для онлайн-уроку LetMe/teens: модуль «Сміливий голос», урок 1 «Датчик хвилювання». Для дітей 9–10 років.

Корабель «Академії пілотів» летить крізь 9 хмар. Кожна хмара — ситуація, у якій треба заговорити. Екіпаж проходить хмару за 4 кроки: **кейс → датчик → сигнали → фраза і кнопка**.

Гра має дві частини:

| Що | Адреса | Хто бачить |
|---|---|---|
| **Екран** | `…/pilot/` | діти (через демонстрацію вкладки в Meet) |
| **Пульт** | `…/pilot/?mode=remote` | лише педагог |

Адреса гри на GitHub Pages: **https://pyatochka-ctrlv.github.io/pilot/**
Пульт: **https://pyatochka-ctrlv.github.io/pilot/?mode=remote**

## 1. Як відкрити екран і пульт

1. Відкрий **Chrome** (або Safari). Обидві вкладки мають бути **в одному браузері й в одному вікні або профілі**, інакше вони не «бачитимуть» одна одну.
2. Вкладка 1 — екран: `https://pyatochka-ctrlv.github.io/pilot/`
3. Вкладка 2 — пульт: `https://pyatochka-ctrlv.github.io/pilot/?mode=remote`
   Зручно винести пульт в окреме вузьке вікно поруч із Meet: потягни вкладку вбік. На пульті є посилання «Відкрити екран гри в новій вкладці».
4. Угорі пульта є індикатор:
   - 🟢 **«Екран на зв'язку»** — усе гаразд;
   - 🔴 **«Екран не відповідає»** — вкладка екрана закрита або відкрита в іншому браузері чи профілі.
5. **Звук** вимкнений. Щоб увімкнути, натисни «Звук» на пульті. Браузер дозволяє звук лише після кліку у вкладці, тому на екрані з'явиться кнопка «Клацни тут, щоб увімкнути звук». Клацни її один раз до початку демонстрації.

Прогрес зберігається в браузері. Якщо випадково перезавантажити або закрити вкладку, гра продовжиться з того самого місця. Щоб почати спочатку, натисни на пульті **«Новий урок»**.

### Хід хмари (з пульта)

1. Тапни номер хмари — на екрані з'явиться кейс (корабель трясеться).
2. **Датчик** — діти пишуть у чат цифри 1–10. Для кожної цифри тисни `+1` (помилився — `−1`). На дузі з'являються крапки розкиду. Імен і середнього немає.
3. **Сигнали** — діти пишуть номери зон тіла 1–7. Тапни ці зони, і вони підсвітяться.
4. **Фраза і кнопка**:
   - голоси за фрази 1/2/3 — `+1` біля фрази. Фраза з найбільшою кількістю голосів підсвічується жовтим;
   - діти обирають кнопку А чи Б. Тапни її, потім **«Старт тренажера»**;
   - після тренажера стрілка датчика опускається в робочу зону, тряска стихає;
   - охочий читає «Сказати вголос: …».
5. **Вихід** — хмара стає світлою, корабель просувається маршрутом.

«Скинути хмару» стирає голоси лише поточної хмари. «Новий урок» стирає все, але спершу просить підтвердження.

## 2. Як у Google Meet показати саме вкладку гри

1. У Meet натисни **«Показати екран»** (значок екрана зі стрілкою) → **«Вкладку»** (у новому інтерфейсі — «Вкладка Chrome»).
2. У списку обери вкладку **«Екран · Зона турбулентності»**. **Не** обирай «Пульт · Зона турбулентності».
3. Щоб діти чули звуки гри, увімкни перемикач **«Також надати доступ до звуку вкладки»**.
4. Натисни **«Поділитися»**. Перемикатися на пульт можна вільно: діти й далі бачать лише вкладку екрана.

Порада: зроби вкладку екрана широкою, бажано на весь монітор (1280×720 або більше). Гра сама підлаштовується під розмір і не має прокрутки.

> Safari не вміє показувати в Meet окрему вкладку, лише вікно або весь екран. Тому для уроку краще Chrome. Якщо працюєш у Safari, відкрий екран і пульт у **різних вікнах** і демонструй лише вікно екрана.

## 3. Як редагувати хмари й кнопки (без програмування)

Усі тексти лежать у двох файлах у папці `data/`. Відредагувати їх можна просто на GitHub: відкрий файл → значок олівця ✏️ → внеси зміни → **Commit changes**. За 1–2 хвилини сайт оновиться сам (вкладка **Actions** покаже зелену галочку).

### `data/clouds.json` — хмари

Кожна хмара — це блок у фігурних дужках `{ … }`:

```json
{
  "id": 1,
  "title": "Біля дошки",
  "case": "Текст ситуації…",
  "phrases": ["Фраза 1", "Фраза 2", "Фраза 3"],
  "sayAloud": "«Що сказати вголос»",
  "buttons": ["reset", "feet"]
}
```

| Поле | Що це |
|---|---|
| `id` | номер хмари на карті (число, без лапок) |
| `title` | назва хмари |
| `case` | текст кейсу |
| `phrases` | рівно **3** фрази «в моменті» |
| `sayAloud` | фраза для «Сказати вголос: …» |
| `buttons` | дві кнопки для голосування: перша — **А**, друга — **Б**. Значення — `id` з `buttons.json` |

На карті вміщується до 9 хмар.

### `data/buttons.json` — кнопки пульта емоцій

```json
{"id":"square","title":"Квадрат","unlocked":false}
```

- `unlocked: true` — кнопку можна обрати й запустити;
- `unlocked: false` — кнопку видно із замочком і підписом «відкриється в модулі «Пульт емоцій»». Запустити її неможливо;
- `hint` — підказка для педагога (видно лише на пульті).

Анімовані тренажери є для `reset` (Перезавантаження) і `feet` (Стопи-магніти). Якщо відкрити іншу кнопку (`unlocked: true`), вона запуститься як простий тренажер: назва, підказка й відлік 12 секунд.

### Правила, щоб нічого не зламати

- Текст завжди в **прямих лапках** `"…"`. Лапки-ялинки «» усередині тексту можна.
- Між блоками й полями ставиться **кома**, а після останнього — ні.
- Апостроф пиши звичайний: `розв'яжи`.
- Якщо помилитися, гра покаже повідомлення: в якому файлі помилка й що виправити.
- Перевірити файл можна на jsonlint.com (встав текст → Validate).

## Для розробника

- Чистий HTML + CSS + vanilla JS, без збірки. Із зовнішніх запитів — лише Google Fonts.
- Синхронізація: `BroadcastChannel`, запасний варіант — подія `storage`. Стан — один JSON у `localStorage` (`zt-state-v1`). Змінює його лише пульт, а екран тільки показує.
- Тренажери рахуються від часу старту (`startedAt`), тому однаково йдуть у всіх вкладках і не збиваються після перезавантаження.
- Екран — сцена 1280×720, яка масштабується під вікно. Мінімальний текст — 28px у координатах сцени.

```
index.html            екран / пульт (?mode=remote)
css/                  base.css, screen.css, remote.css
js/common.js          кольори, зони, іконки, утиліти
js/store.js           стан і синхронізація вкладок
js/trainers.js        таймлайни тренажерів
js/sound.js           звуки WebAudio (без файлів)
js/screen.js          екран
js/remote.js          пульт
js/main.js            завантаження data/*.json і запуск
data/clouds.json      хмари
data/buttons.json     кнопки
```

Локальний запуск (через `file://` JSON не завантажиться):

```bash
python3 -m http.server 8000
```

Потім відкрий `http://localhost:8000/` і `http://localhost:8000/?mode=remote`.

### Публікація на GitHub Pages

Один раз: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Після цього кожен push у `main` публікує сайт (workflow `.github/workflows/pages.yml`).
